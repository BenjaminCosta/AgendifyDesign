# Agendify Design Studio

Estudio digital premium especializado en diseño web, desarrollo y marketing digital.

## Stack tecnológico

- **React** + **TypeScript**
- **Vite** (build tool)
- **Tailwind CSS** (estilos)
- **shadcn/ui** (componentes UI)
- **Framer Motion** (animaciones)

## Desarrollo local

```sh
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Build de producción
npm run build
```
